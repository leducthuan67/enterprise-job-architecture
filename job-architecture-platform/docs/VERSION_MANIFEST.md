# Job Architecture Platform Version Manifest

| Component | Baseline | Synchronization rule |
|---|---|---|
| Platform | V6 | Release features and data schema are authoritative for implemented capability |
| Methodology | V6-aligned | Must follow `docs/CORE_DESIGN_PRINCIPLES.md` |
| Training | V6-aligned | Training examples, workflow and screenshots must match the deployed Platform release |
| Consulting projects | Project-specific, mapped to V6 | Client-approved source IPE data and project decisions remain immutable unless formally approved |

Every release must update this manifest with release ID, effective date, code commit, deployment URL/status, changes, affected documents and migration notes. A document must not claim a feature is available until it is verified in the deployed release.

**Current baseline:** V6 prototype. See `docs/CORE_DESIGN_PRINCIPLES.md` for mandatory acceptance criteria and current limitations.
